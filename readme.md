# Advent of Code

Solutions for Advent of Code 2025.

Solutions to puzzles are imlemented in both Python and C.

## Running Python solutions

To run solution for day 1 part 1, do:

    $ python3 day1-1.py

## Building and running C solutions

Each C file is a complete executable.
To build and run solution for day 1 part 1, do for example:

    $ gcc day1-1.c
    $ ./a.out
